# 社交 · dsh-share-chat

在 DSH 里和好友聊天，并把手上的对话一键分享给对方——不是截图，是带工具调用和回复的结构化快照。
消息不经过任何模型，**不消耗 token**；内容存在你自己的 relay 服务器上。

还内置了「鱼塘摸鱼」小游戏：点聊天页顶栏的 `🎮 摸鱼` 就能在 DSH 里玩，窗口大小可在 **设置 → 社交小游戏** 里调。

> 当前版本 **0.3.0**（npm 包名 `dsh-share-chat`）。更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## 特性

- **一对一手动好友**：输入对方 ID 即互为好友，没有申请/同意流程
- **文字 / 表情 / 图片 / 视频 / 音频 / 任意文件**：图片视频直接内嵌，其它文件带类型图标和大小（单件上限 50 MB，服务端决定）
- **对话快照**：「分享这一轮」把最后一轮的提问、工具调用、回复打包成卡片，对方点开就能看；不含思考过程和运行时注入的上下文
- **音视频会议**：点 `📹 开会`，新建房间或输房间号加入；≤6 人，音频+视频+屏幕共享，点对点直连、无时长限制
- **内置小游戏**：「鱼塘摸鱼」的浏览器移植版，iframe 原样嵌进来，账号/存档还是游戏自己那套
- **跟随 DSH 主题**：整套界面只用 `--dsw-alias-*` token，亮色/暗色自动适配
- 5 秒轮询，无 WebSocket；掉线后下一次轮询自动恢复

## 安装

> **不需要安装 Git。** 下面的三种方式都不走 git；只有把 `git+https://…` 这种地址丢给 DSH 时，pnpm 才会去调本机的 `git`，机器上没有就会报 `ERR_PNPM_GIT_RESOLVE_FAILED`。

### 方式 A：npm（推荐，一条命令）

```bash
dsh plugin add dsh-share-chat
```

走 npm registry，不需要 Git；升级就是 `dsh plugin add dsh-share-chat@最新版本`。

### 方式 B：tgz 安装包

```bash
dsh plugin add https://xdxy-pet.com/dl/dsh-share-chat-0.3.0.tgz
```

装完刷新页面，左侧栏出现 **社交**（若在「更多」里，点图钉固定）。

### 方式 C：本地文件夹

1. 下载本仓库 ZIP 解压到任意位置，例如 `D:\plugins\dsh-share-chat`
2. DSH → 左侧栏 **插件** → **添加插件** → 选这个文件夹
3. 刷新页面

缺点是没有任何版本追踪，换版本要重新选一次文件夹。

### 方式 D：从仓库/本地装（Git 或文件夹）

```bash
# 发布者：去掉 package.json 里的 "private": true，并把 name 改成可发布的包名
npm publish
# 使用者
dsh plugin add <包名>
```

### 为什么别人的插件不需要 Git

DSH 用 pnpm 管插件：

| 安装源 | 需要 Git？ |
|---|---|
| npm 包名（registry） | 不需要，纯 HTTPS 下载 |
| `https://…/xxx.tgz` | 不需要 |
| 本地文件夹 `file:` | 不需要 |
| `git+https://…` / `github:user/repo` / `git+ssh://…` | **需要**，pnpm 要 `git ls-remote` 和 `git clone` |

别人能用得更省事，通常只是因为他们把包装到了 npm，或者发的是 tgz。
本插件是 `private` 包、只发了仓库，所以直接用仓库地址装才会卡在 git 上。

更细的安装/排错说明见 [docs/INSTALL.md](docs/INSTALL.md)。

## 第一次使用

1. 左侧栏 → **社交**
2. 点 **注册**，填：
   - **服务器地址**：已预填 https://xdxy-pet.com/relay ，不用改
   - **邀请码**：找发插件的人要
   - **账号名**：2–20 位，中文可以
   - **密码**：至少 6 位，**一定要设**（账号在服务器上，换电脑换端口都只认密码）
3. 进去后在左栏输入对方 ID 加好友（对方那边会自动出现你）
4. 选一个好友开始聊：`Enter` 发送，`Shift+Enter` 换行

老账号没设过密码的，点登录页的「没设过密码？」，用邀请码补一个；也保留 token 登录兜底。

## 分享一段对话

在会话里点 **社交** 标签页（跟「对话」「轨迹」那一排），顶部点 **🐟 分享这一轮**：

1. 出现预览，逐行列出将要发出去的内容
2. 选好友 → 发送

包含：你的提问、工具调用（压成一行）、我的回复；**不包含**思考过程与运行时上下文（`<system-reminder>`、时间戳、工作目录等）。
只取最后一轮，每段最多 1500 字，最多 8 段。

## 音视频会议

- 聊天页顶栏 **📹 开会**：`＋ 新建会议` 拿到 6 位房间号，或输入房间号加入；`📋` 复制房间号发给好友
- 右上角是参会人视频格，底部工具栏：`🎤` 麦克风、`🎥` 摄像头、`🖥` 共享屏幕、`📋` 房间号、`🚪` 离开
- 窗口可拖标题栏移动、右下角改大小，`Esc` 离开
- **没有时长限制**：媒体是浏览器之间 P2P 直连，relay 只转发 SDP/ICE，不经过服务器带宽
- 需要的只是摄像头/麦克风权限（DSH 在本机 `127.0.0.1` 上，属于安全上下文，能正常授权）
- 对称 NAT / CGNAT 环境下可能连不通，界面会标 `⚠ 可能需要对端 TURN`；彻底解决要在服务器上加 coturn（见 docs/MEETING.md）

## 内置小游戏

- 入口：聊天页顶栏 **🎮 摸鱼**
- 窗口：右下角浮动窗，拖标题栏移动、拉右下角改大小
- 默认尺寸：**设置 → 社交小游戏**（预设 340×600 / 390×760 / 480×900，也可自定义）
- 游戏本体部署在 `https://xdxy-pet.com/game/`，和鱼塘的 `/api/fish/` 同源

移植层和部署脚本**不放在插件仓库里**（它们会触发 dsh.so 的安全扫描），部署方式见 [docs/GAME.md](docs/GAME.md)。

## 更新 / 卸载

- 更新：换一个更新的 tgz 地址重新 `dsh plugin add`（或插件页里的更新）
- 卸载：DSH → 插件 → 找到「社交」→ 停用或移除

## 数据流向与隐私

- 聊天 / 好友 / 消息 / 快照 → 你自己的 relay（默认 `https://xdxy-pet.com/relay`，登录页可改）
- 小游戏 → `https://xdxy-pet.com/game/` + `https://xdxy-pet.com/api/fish/`（同一台服务器，游戏自己的账号体系）
- Host 侧（`index.js`）只在本机回环地址上开两条**只读**的会话调试路由，公网部署直接 403
- relay 明文存储：消息与快照是 JSON 文件，快照 7 天过期；浏览器 localStorage 里存 bearer token，共用电脑注意退出

## 已知限制

- 只分享**最后一轮**；每段最多 1500 字、最多 8 段
- 分享过滤是黑名单（key 名 + 节点 kind），不保证 100% 不漏，发送前请过一眼预览
- 没有群聊、已读回执、撤回、语音、好友申请
- 消息 5 秒轮询，不是实时推送
- 小游戏在网页端没有微信登录、没有激励视频（广告接口降级为「不可用」）、没有游戏圈
- 游戏账号与聊天账号是两套，暂未打通
