# 社交（DSH 插件）

在 DSH 里和好友聊天，并且能把一段对话一键分享给对方——不是截图，是带工具调用和回复的结构化快照。

消息不经过任何模型，**不消耗 token**。所有内容存在你自己的服务器上。

## 需要什么

- DeepSeek Harness **桌面端**（Web 版也行，但入口都在桌面端侧栏）
- 一个邀请码（找发给你这个插件的人要）

## 安装

1. 把这个文件夹解压到任意位置，比如 `D:\plugins\share-chat`
2. 打开 DSH → 左侧栏 **插件** → **添加插件** → 选这个文件夹
3. 装好后左侧栏会出现 **社交**（如果没有，去左侧栏底部的「更多」里点图钉固定）

## 第一次使用

1. 左侧栏 → **社交**
2. 点 **注册**
3. 填：
   - **服务器地址**：已预填，不用改
   - **邀请码**：找发插件的人要
   - **账号名**：中文可以
   - **密码**：至少 6 位。**一定要设**——账号在服务器上，有密码换电脑、换端口都能登
4. 进去后，在左栏输对方账号 ID 加好友（对方那边会自动出现你）
5. 选一个好友开始聊：`Enter` 发送，`Shift+Enter` 换行

## 分享一段对话

在会话里点 **社交** 标签页（跟「对话」「轨迹」那一排），顶部有 **「分享这一轮」**：

1. 点它 → 出现**预览**，一眼能看到将要发出去的内容
2. 选好友 → 发送

分享内容包含：你的提问、工具调用（压成一行）、我的回复。
**不包含**：思考过程、系统注入的上下文（运行时时间戳、工作目录等）。

## 已知限制

- 只分享**最后一轮**，不是整个会话
- 消息 5 秒轮询，不是实时推送
- 没有群聊、已读回执、撤回、图片、语音
- 服务器明文存储，分享的快照 **7 天后过期**
- 服务器地址和 token 存在浏览器本地；**换登录端口会掉登录，用密码重新登即可**

## 卸载

DSH → 插件 → 找到「社交」→ 停用或移除。
