# 社交（DSH 插件）

在 DSH 里和好友聊天，并且能把一段对话一键分享给对方——不是截图，是带工具调用和回复的结构化快照。

除了聊天，还长出了一整套「一起玩」的东西：**视频会议**、**KTV**、**麻将**、**串门复刻好友的插件配置**、**捏脸**、**桌面宠物**。

消息不经过任何模型，**不消耗 token**。所有内容都存在你自己的服务器上。

## 需要什么

- DeepSeek Harness **桌面端**（Web 版也行，但入口都在桌面端侧栏）
- 一个邀请码（找发给你这个插件的人要）

## 安装

**从 npm 装（推荐）**

```bash
dsh plugin add dsh-share-chat
```

**装不上 npm 时（镜像没同步 / 没网）**

```bash
dsh plugin add https://xdxy-pet.com/dl/dsh-share-chat-0.29.0.tgz
```

**从文件夹装**

1. 把仓库解压到任意位置，比如 `D:\plugins\share-chat`
2. 打开 DSH → 左侧栏 **插件** → **添加插件** → 选这个文件夹
3. 装好后左侧栏会出现 **社交**（如果没有，去左侧栏底部的「更多」里点图钉固定）

> 从 Git 仓库装需要本机有 Git；上面两种方式都不需要。

## 第一次使用

1. 左侧栏 → **社交**
2. 点 **注册**
3. 填：
   - **服务器地址**：已预填，不用改
   - **邀请码**：找发插件的人要
   - **账号名**：中文可以
   - **密码**：至少 6 位。**一定要设**——账号在服务器上，有密码换电脑、换端口都能登
4. 进去后，在左栏输对方账号 ID 加好友（对方那边会自动出现你）
5. 选一个好友开始聊：`Enter` 发送，`Shift+Enter` 换行

## 聊天

- 好友和群聊混排在一个侧栏里，群消息带发送者名字和头像
- 支持图片、文件（点一下下载）
- 顶部一排按钮：**开会 / KTV / 麻将 / 摸鱼 / 串门 / 退出**

## 分享一段对话

在会话里点 **社交** 标签页（跟「对话」「轨迹」那一排），顶部有 **「分享这一轮」**：

1. 点它 → 出现**预览**，一眼能看到将要发出去的内容
2. 选好友 → 发送

分享内容包含：你的提问、工具调用（压成一行）、我的回复。
**不包含**：思考过程、系统注入的上下文（运行时时间戳、工作目录等）。

## 视频会议

- 点 **📹 开会**，把房间号发给对方，对方点「开会」填号即可
- **点对点直连**，媒体流不过服务器；**没有时长限制**
- ≤6 人；支持共享屏幕、静音、关摄像头
- 对称型 NAT 可能需要 TURN（目前只带公共 STUN）

## KTV

- 点 **🎤 KTV** 开包厢，进房只开麦、不开摄像头
- 有排队点歌列表，浮窗可以拖动、可以缩放
- 适合一边写代码一边挂着

## 麻将

- 点 **🀄 麻将** 开一桌，缺的位置由机器人补
- 牌面和操作在浮窗里，可拖动缩放
- 纯娱乐，不涉及任何积分/交易

## 串门（营地）

把「我装了哪些插件、什么主题」做成一张**营地卡片**，好友之间互相串门；看中了可以一键复刻。

- **发布我的营地**：填营地名 + 一句话签名，可见性选「仅好友 / 公开广场 / 凭访问码」
- **保留最近 3 版**，能回看上一版
- **进去看看**：插件清单会标 `已有` / `可安装` / `版本不同` / `内置`
- **复刻**：勾选 → 逐项确认来源 → 安装 → 结果列表 → **一键撤销这次安装**
- 安全边界：只接受 `包名@精确版本`、`git+https://…#commit`、`https://….tgz`；**`file:` / `link:` / 本地路径一律拒绝**；每次安装都要一次性 nonce + 二次确认

> 营地快照只有营地名、签名、插件清单，**不含**路径、凭据、会话内容。

## 捏脸

- 串门面板左上角点「捏脸」打开**全屏工作室**
- **45 个参数**、11 组滑杆：脸型 / 眼睛 / 眉毛 / 鼻子 / 嘴巴 / 耳朵 / 肤色 / 头发 / 妆容 / 配饰 / 身形
- 两套画风：**Q 版鲸鱼娘**（默认）和**半写实**，参数通用
- **3D / 2D 切换**：3D 是真 WebGL 渲染（参数化头部网格 + 脸部贴图 + 卡通光照 + 描边 + 转台）
- 6 套预设、随机、撤销/重做（60 步）
- **脸码**：`FACE2-xxxx`，复制发给别人，粘贴就能用同一张脸
- 老形象（哈希生成的那版）会自动迁移，不会换脸

## 桌面宠物

- 捏好的小人儿可以放到桌面上，**可拖动、可隐藏**
- 右键有菜单；位置记在本地

## 小游戏

- 点 **🎮 摸鱼** 打开浮窗版《鱼塘摸鱼》，可拖拽、可缩放，窗口大小在**设置 → 社交 → 小游戏**里改

## 隐私与边界

- 服务器**明文存储**消息，分享的快照 **7 天后过期**；别发敏感内容
- 没有端到端加密；会议是 P2P，但信令经过服务器
- 账号和 token 存在浏览器本地；**换登录端口会掉登录，用密码重新登即可**
- 复刻插件等于在**你自己机器上**安装对方选的包，务必看清来源再点确认

## 已知限制

- 只分享**最后一轮**，不是整个会话
- 消息 5 秒轮询，不是实时推送
- 会议 ≤6 人；对称 NAT 可能要 TURN
- 没有已读回执、撤回、语音消息
- 3D 形象目前是「球面头部 + 贴图五官」，还不是细分网格建模
