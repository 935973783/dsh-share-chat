# 社交

在 DSH 里和好友聊天，好友发来的对话快照可以直接展开看。有两个入口，共用一份登录状态。

## 怎么用

- **左侧栏「社交」**（常驻，不依赖会话）——主入口。第一次可能出现在左侧栏底部的「更多」菜单里，点那一行右侧的图钉即可固定到左侧栏。
- **会话里的「社交」标签页**——在 Chat / Trajectory 那一排，方便在某个会话里顺手看一眼。

打开后：

1. 第一次用选「注册」：填服务器地址（默认 `https://xdxy-pet.com/relay`）、邀请码、账号名、密码（至少 6 位）。账号名支持中文。
2. 登录后，在左栏输入对方 ID 加好友（对方也会自动把你加为好友），然后选一个好友开始聊。
3. 底部输入框：`Enter` 发送，`Shift+Enter` 换行。每 5 秒拉一次新消息。

**用密码登录**：账号和密码存在服务器上，换端口、换电脑都只认密码。老账号没设过密码的，点登录页的「没设过密码？」，用邀请码补一个即可。也保留用 token 登录的兜底方式。

## 现在能做什么

- 注册、用 token 登录、退出
- 加好友（互相添加）
- 一对一发文字消息、收消息
- 收到对话快照时展开查看（标题、用户消息、工具调用、回复）
- **一键分享当前会话**：在会话里的「社交」tab 顶部点「分享这一轮」，选好友发出去。只取**最后一轮**，每段最多 1500 字，工具调用压成一行短摘要

## 明确的限制

- 「分享这一轮」以 `turn-tail` 边界切分，取最后一个 turn；跨多轮的长回答只带最后一段
- **不包含思考过程**：reasoning / thinking 类内容按 key 名和节点 kind 双重过滤，整棵子树跳过
- 会剥掉运行时注入的 `<system-reminder>` 上下文（时间戳、工作目录、权限策略那类）
- 分享内容按「用户 / 工具 / 回复」三类归一化，原始 Markdown 结构和附件不会带过去
- 过滤是黑名单，不是白名单：不保证 100% 不漏，分享前建议自己过一眼
- 没有好友申请与同意流程，双方互相添加即成立。
- 没有群聊、已读回执、撤回、图片、语音。
- 消息 5 秒轮询，不是实时推送；断线后下一次轮询自动恢复。
- 服务器不加密存储：消息和快照以明文 JSON 落在 relay 的 `/opt/dsh-relay/data/`，快照 7 天过期。
- 浏览器 localStorage 里存的是 bearer token，共用电脑时注意退出。

## 服务器地址

默认指向 `https://xdxy-pet.com/relay`，可在登录页改。relay 只存信封（谁发给谁 + 时间 + 快照引用），不解析消息内容语义。
